# Gigle-AI (SSCR Manila Institutional Suite)

Multimodal AI multi-device Swiss-knife framework dedicated to NGO and community-support operations, integrated with San Sebastian College - Recoletos (SSCR) Manila and Jennifer Logic.

## Core Features
- **Presidential Executive Command:** Direct oversight channel for **Fr. Romeo Ben Potencio, OAR**, operating under the "Last Call" principle.
- **Master Calendar & Scheduling:** Integrated monthly work patterns and institutional scheduling visible across dedicated display pages.
- **Psychological Support Gateway:** Confidential, voluntary counseling triage linked securely with the SSCR Psychology Department under strict data privacy protocols.
- **Multimodal Field Assistant:** Lightweight infrastructure supporting community-building, emergency logistics, and botanical triage.
